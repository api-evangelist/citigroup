# Citigroup (citigroup)
Citigroup is a global diversified financial services holding company providing consumers, corporations, governments, and institutions with a broad range of financial products and services. Citi exposes its API surface through the Citi Developer Hub, a unified developer portal spanning the bank's retail, commercial, and Treasury and Trade Solutions (TTS) lines of business.

## APIs

### Citi Accounts and Transactions API
Authorized access to retail customer accounts, balances, and transaction histories. Authentication uses OAuth 2.0.

**Human URL:** [Citi Accounts and Transactions](https://sandbox.developerhub.citi.com/api/united-states/retail-bank/accounts/accounts-and-transactions/documentation)

#### Tags:

 - Accounts, Balances, Banking, Statements, Transactions

### Citi Money Movement API
Authorized payment initiation from Citi accounts including domestic ACH, wire, and book transfers.

**Human URL:** [Citi API Catalog](https://sandbox.developerhub.citi.com/api-catalog-list)

#### Tags:

 - ACH, Money Movement, Payment Initiation, Payments, Wire Transfer

### Citi Authorize API
OAuth 2.0 authorization-code and consent flows required for third-party access to Citi account data and payment initiation.

**Human URL:** [https://developer.citi.com/](https://developer.citi.com/)

#### Tags:

 - Authorization, Consent, OAuth, SCA

### Citi Customers API
Authorized access to customer profile information for onboarding and KYC workflows.

**Human URL:** [https://developer.citi.com/](https://developer.citi.com/)

#### Tags:

 - Customers, Identity, KYC, Profiles

### Citi Onboarding API
Digital account opening, document submission, and KYC workflows for new retail customers.

**Human URL:** [https://developer.citi.com/](https://developer.citi.com/)

#### Tags:

 - Account Opening, Customer Onboarding, KYC, Origination

### Citi Pay with Points API
Citi cardholder ThankYou point and rewards redemption at merchant checkouts and partner applications.

**Human URL:** [https://developer.citi.com/](https://developer.citi.com/)

#### Tags:

 - Loyalty, Pay with Points, Rewards

### Citi Utilities API
FX rates, branch and ATM locators, and cut-off times used to support transactional workflows.

**Human URL:** [https://developer.citi.com/](https://developer.citi.com/)

#### Tags:

 - FX Rates, Locator, Reference Data, Utilities

### CitiConnect API
Corporate treasury and trade integration channel exposing APIs for real-time payments, FX, statements, direct debits, faster payments, and proof-of-payment for enterprise clients connecting through ERP and TMS systems.

**Human URL:** [CitiConnect API Portal](https://www.citigroup.com/global/insights/citiconnect-api-portal)

#### Tags:

 - CitiConnect, Corporate Banking, ERP Integration, Treasury, TTS
